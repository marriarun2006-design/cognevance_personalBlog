# Cognevance Personal Blog Website

## Overview
A responsive personal blogging platform built with Python Flask, SQLite, HTML, CSS and JavaScript.

## Features
- User registration and login
- Password hashing
- Create, edit and delete blog posts
- User dashboard
- Responsive frontend
- SQLite database
- Session-based authentication

## Run locally
```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000`.

## Repository name
`cognevance_personalBlog`

## Deployment
Deploy the Flask application on Render, Railway, or PythonAnywhere. Set a strong `SECRET_KEY` environment variable. For production, use a persistent database instead of temporary local storage.
